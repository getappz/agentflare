This page lists every `agentflare` subcommand with the job it performs. Flags and
per-subcommand help are generated by the binary:

```bash
agentflare --help
agentflare <command> --help
```

Running `agentflare` with no subcommand prints the banner, version, and the same top-level
map.

## Setup and maintenance

| Command | Purpose |
|---|---|
| `agentflare init --agent <host>` | Wire hooks, MCP, and rules into a coding agent. Idempotent. |
| `agentflare doctor` | Diagnose host wiring and report conflicts. |
| `agentflare agents` | Inspect and manage detected coding-agent installs. |
| `agentflare alias` | Manage shell aliases installed for agentflare commands. |
| `agentflare update [version]` | Update to the latest release, or a specific version. |
| `agentflare uninstall` | Remove hooks, configuration, and installed files. |
| `agentflare dev-install` | Build the current checkout and install it over the running binary. |
| `agentflare clean` (alias `cleanup`) | Plan, then clean merged branches, worktrees, and build artifacts. |
| `agentflare config` | Manage `~/.agentflare/config.toml` settings. |
| `agentflare about` (alias `logo`) | Print banner and version information. |
| `agentflare hook <event>` | Internal lifecycle entry point invoked by a host. Not for direct use. |

## Running agents

| Command | Purpose |
|---|---|
| `agentflare run <agent>` | Launch an agent through mise with `.dev.vars` injected. |
| `agentflare work <target> --agent <agent>` | Claim an item, run an agent in an isolated worktree, and report back. |
| `agentflare apps run <dir>` | Run an AgentFlare App end-to-end from its self-contained directory. |
| `agentflare wrap claude` / `agentflare unwrap claude` | Install or remove the opt-in Claude shell wrapper (`claude-code` is an alias). |
| `agentflare agents` | List detected agent CLIs and their versions. |

## Optimization

| Command | Purpose |
|---|---|
| `agentflare cost` | Show token and dollar cost, optionally by project. |
| `agentflare optimize` (aliases `flare`, `opt`) | Compress output, minimalism-check code, or score transcript relevance. |
| `agentflare code` | Static analysis for the current repo (change impact). |
| `agentflare decide` | Typed-decision layer (Jev): check the connection. |
| `agentflare insights` | Unified, local-first session observability for Claude, Codex, and opencode. |

## Coordination

| Command | Purpose |
|---|---|
| `agentflare item` | List, get, cancel, pause, resume, or redispatch work items. |
| `agentflare claim` | Claim an item for the current session. |
| `agentflare project` | Manage projects. |
| `agentflare job` | Control dispatched jobs (cancel, pause, resume). |
| `agentflare review` | Submit findings for a diff/PR, run consensus, inspect scores. |
| `agentflare handoff` | Hand a work product to another agent's inbox. |
| `agentflare message` | Message live sessions (send, list, inbox, watch). |
| `agentflare channel` | Send and inspect messages on coordination channels. |
| `agentflare artifacts` | Serve live-shareable artifact pages from agent sessions. |
| `agentflare workflow` | Run and inspect durable agent pipelines. |
| `agentflare coaching` | Manage rules nudged to agents mid-session. |
| `agentflare vent` | Capture friction and feedback as structured data. |
| `agentflare pr` | Open stamped PRs and manage cross-instance PR ownership. |
| `agentflare github-bridge` | Configure the GitHub work-item bridge for this repo. |
| `agentflare serve` | Serve the dashboard and execution host. |
| `agentflare daemon` | Manage the background daemon (dashboard, bridge, watchers). |

## Knowledge

| Command | Purpose |
|---|---|
| `agentflare docs search <query>` | Search cached third-party API documentation. |
| `agentflare docs get <package>` | Fetch and cache a package's docs. |
| `agentflare docs list` | List what is already cached. |
| `agentflare docs refresh <package>` | Refresh a cached package, optionally at a new version. |
| `agentflare memory` | Read and write cross-session agent memory. |
| `agentflare skill` | Discover, install, and manage skills for coding agents. |
| `agentflare store` | Inspect the local hybrid-search store (chunks, vectors, metadata). |

## Browser

`agentflare browser` is agent-first browser automation: `open`, `snapshot`, `click`, `fill`,
`read`, `screenshot`, `pdf`, `eval`, `tabs`, `network`, `cookies`, `storage`, `batch`, and
more. Run `agentflare browser --help` for the full subcommand list.

## Auth, secrets, and git

| Command | Purpose |
|---|---|
| `agentflare auth` | Manage credentials for connected services. |
| `agentflare vault` | Store secrets in the encrypted local vault; values are read from stdin. |
| `agentflare gateway` | Manage third-party gateway credentials and connections. |
| `agentflare git` | Git helpers for agent worktrees and branch hygiene. |
| `agentflare mcp` | Start the MCP stdio server. `init` normally wires this for you. |

## Slash commands

Several surfaces are also exposed as MCP Prompts (native slash commands in hosts that
support them): `/optimize`, `/artifact`, `/handoff`, `/git`, and the
`/optimize-{review,audit,debt,gain,help,playbook,no-hallucination}` sub-skills. See the
[MCP tools reference](/docs/reference/mcp-tools/#mcp-prompts-slash-commands) for the full
list.
