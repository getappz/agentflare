agentflare is a single Rust binary — no Node, no runtime dependencies — that wires into
Claude Code, Codex, Cursor, Windsurf, VS Code, Cline, Continue, and opencode. It cuts the
token and cost overhead of a single agent session, and it lets several agents work the
same codebase without colliding.

It is in beta. Interfaces can change between releases; check the
[release notes](https://github.com/getappz/agentflare/releases) before upgrading.

## Install

Linux and macOS:

```bash
curl -fsSL https://agentflare.dev/install.sh | sh
```

Homebrew, Scoop, `cargo install`, and build-from-source are covered in
[Installation](/docs/get-started/install/). Then connect your agent:

```bash
agentflare init --agent claude-code
```

## Two layers

**Optimization** makes one session cheaper. It compresses what the agent reads, remembers
decisions across sessions, keeps package documentation current, and nudges the model away
from over-engineering. See [Concepts](/docs/concepts/optimization/).

**Coordination** makes several sessions safe. It provides a local backlog with claiming,
review consensus, versioned artifacts, handoffs, a dashboard, and outbound notifications —
all backed by SQLite, with no daemon required for the core primitives. See
[Concepts](/docs/concepts/coordination/).
